## Overview

Canvas Draw is a compact drawing application that uses the HTML canvas element as its workspace. It runs in a web browser, giving users a simple way to create drawings without installing a native desktop program.

The project is designed for quick sketches, creative experiments, and basic browser-based artwork. Because it is delivered as a web application, drawing can be done from a compatible browser with the interface focused on the canvas itself.
